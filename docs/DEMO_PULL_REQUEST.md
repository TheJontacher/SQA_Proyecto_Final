# Demostración del pipeline CI/CD

Este cambio demuestra el flujo de integración continua del Sistema de Gestión Clínica.

## Controles automáticos

- BUILD: validación de dependencias y sintaxis.
- TEST: ejecución de 91 pruebas y cobertura mínima del 60%.
- ANALYZE: Ruff y SonarQube Cloud.
- REPORT: generación de resultados y evidencias.

Los cambios se integran mediante Pull Requests sujetos a verificaciones automáticas.
